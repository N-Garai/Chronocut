# Cuts & Transitions

Use these as mechanical, reviewable editing passes. Never silently rewrite the
user's message — only assemble the timeline.

- **hard_cut**: instant switch. Use between shots of clearly different scenes or
  for punchy rhythmic edits. First shot of the video is always a hard cut.
- **crossfade_0.5s**: gentle 0.5s dissolve. Default connective tissue between
  reflective beats.
- **dissolve**: longer, dreamy dissolve for memory / nostalgia.
- **dip_black**: brief fade through black. Use between major acts (hook → setup → payoff).
- **match_cut**: cut on a visual/action match (e.g. similar motion or color across
  two shots). Use sparingly; only when the footage genuinely matches.
- **J-cut / L-cut**: let the next shot's audio lead its picture (J) or the prior
  shot's audio linger into the next (L). ChronoCut approximates this by overlapping
  narration; prefer crossfades where available.

Rule: keep transitions subtle and consistent. A timeline that jumps between many
transition types reads as broken.
